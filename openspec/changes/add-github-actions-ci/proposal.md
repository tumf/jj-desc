# 変更提案: GitHub Actions CI でユニットテストを実行

## 概要

GitHub Actions を使用して、プルリクエストおよび main ブランチへのプッシュ時に Rust のユニットテストを自動実行する CI ワークフローを追加する。

## 背景

現在、`jj-desc` プロジェクトには複数のユニットテストが存在する（`error.rs`, `provider.rs`, `config.rs`, `prompt.rs`）が、CI による自動テスト実行が設定されていない。これにより、コード変更時のリグレッション検出が手動に依存している。

## 目標

1. プルリクエスト作成時にテストを自動実行
2. main ブランチへのマージ時にテストを実行
3. テスト失敗時にマージをブロック可能にする
4. 複数の Rust バージョンでのテスト（minimum supported: 1.85）

## スコープ

### 含まれるもの

- `.github/workflows/ci.yml` の作成
- ユニットテスト (`cargo test`) の実行
- コードフォーマットチェック (`cargo fmt --check`)
- Clippy によるリント (`cargo clippy`)

### 含まれないもの

- リリース自動化（別提案で対応）
- コードカバレッジレポート（将来の拡張）
- インテグレーションテスト（現時点では存在しない）

## 影響

- 新規ファイル: `.github/workflows/ci.yml`
- 既存コードへの変更: なし

## リスク

- 特になし。既存の開発フローに影響を与えない追加機能。
