# タスク: GitHub Actions CI の追加

## 実装タスク

- [ ] **1. ワークフローディレクトリの作成**
  - `.github/workflows/` ディレクトリを作成
  - 依存: なし

- [ ] **2. CI ワークフローファイルの作成**
  - `.github/workflows/ci.yml` を作成
  - テスト、リント、フォーマットチェックの3ジョブを定義
  - 依存: タスク1

- [ ] **3. テストジョブの実装**
  - Rust 1.85 (MSRV) と stable の両方でテスト
  - `cargo test --all-features` を実行
  - rust-cache を設定
  - 依存: タスク2

- [ ] **4. リントジョブの実装**
  - `cargo clippy -- -D warnings` を実行
  - 警告をエラーとして扱う
  - 依存: タスク2

- [ ] **5. フォーマットチェックジョブの実装**
  - `cargo fmt --check` を実行
  - 依存: タスク2

## 検証タスク

- [ ] **6. ローカルでのテスト確認**
  - `cargo test` が成功することを確認
  - `cargo clippy` が警告なしで通ることを確認
  - `cargo fmt --check` が通ることを確認
  - 依存: なし（並列実行可能）

- [ ] **7. プルリクエストでの動作確認**
  - テスト用ブランチを作成してPRを開く
  - CI が正常に実行されることを確認
  - 依存: タスク2-5

## 並列実行可能なタスク

- タスク3, 4, 5 は並列実装可能
- タスク6 は他のタスクと並列実行可能
