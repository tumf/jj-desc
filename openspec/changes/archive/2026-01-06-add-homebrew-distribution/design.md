# Design: Homebrew Distribution Support

## Architecture Overview

```
┌─────────────────────────────────────────────────────────────┐
│                    Release Workflow                          │
│  (.github/workflows/release.yml)                            │
├─────────────────────────────────────────────────────────────┤
│  1. plan          - Generate build plan with dist plan      │
│  2. build-local   - Build binaries for each platform        │
│  3. build-global  - Generate installers and checksums       │
│  4. host          - Create GitHub Release                   │
│  5. publish-homebrew-formula - Push Formula to tap          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  tumf/homebrew-tap                          │
├─────────────────────────────────────────────────────────────┤
│  Formula/                                                   │
│  └── jj-desc.rb   ← Auto-generated by cargo-dist           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  User Installation                          │
├─────────────────────────────────────────────────────────────┤
│  $ brew tap tumf/tap                                        │
│  $ brew install jj-desc                                     │
│  # or                                                       │
│  $ brew install tumf/tap/jj-desc                            │
└─────────────────────────────────────────────────────────────┘
```

## Components

### 1. cargo-dist Configuration (Existing)

`dist-workspace.toml`:
```toml
installers = ["shell", "powershell", "homebrew"]
tap = "tumf/homebrew-tap"
publish-jobs = ["homebrew"]
```

cargo-dist automatically generates:
- Formula file (`jj-desc.rb`)
- Download URLs and checksums

### 2. homebrew-tap Repository (New)

Homebrew taps must follow specific naming conventions:
- Repository name: `homebrew-tap` (arbitrary name allowed, but `homebrew-` prefix is conventional)
- Structure:
  ```
  homebrew-tap/
  └── Formula/
      └── jj-desc.rb
  ```

Tap name: `tumf/tap` (the `homebrew-` prefix is omitted)

### 3. GitHub Secrets

`HOMEBREW_TAP_TOKEN`:
- Purpose: Used by the `publish-homebrew-formula` job to push to the tap repository
- Permissions: Write access to `tumf/homebrew-tap`
- Token type: Personal Access Token (classic or fine-grained)

## Formula File Structure

Example Formula generated by cargo-dist:

```ruby
class JjDesc < Formula
  desc "Generate jj commit descriptions using LLM"
  homepage "https://github.com/tumf/jj-desc"
  version "0.1.0"

  on_macos do
    on_arm do
      url "https://github.com/tumf/jj-desc/releases/download/v0.1.0/jj-desc-aarch64-apple-darwin.tar.xz"
      sha256 "..."
    end
    on_intel do
      url "https://github.com/tumf/jj-desc/releases/download/v0.1.0/jj-desc-x86_64-apple-darwin.tar.xz"
      sha256 "..."
    end
  end

  on_linux do
    on_arm do
      url "https://github.com/tumf/jj-desc/releases/download/v0.1.0/jj-desc-aarch64-unknown-linux-gnu.tar.xz"
      sha256 "..."
    end
    on_intel do
      url "https://github.com/tumf/jj-desc/releases/download/v0.1.0/jj-desc-x86_64-unknown-linux-gnu.tar.xz"
      sha256 "..."
    end
  end

  def install
    bin.install "jj-desc"
  end
end
```

## Security Considerations

### Token Permission Minimization

When using fine-grained PAT:
- Repository access: `tumf/homebrew-tap` only
- Permissions:
  - Contents: Read and write
  - Metadata: Read

### Token Expiration

- Recommended: 90 days or no expiration
- For no expiration, consider periodic rotation

## Alternatives

### 1. Submit PR to homebrew-core

Pros:
- Direct installation via `brew install jj-desc` (no tap needed)
- Higher trustworthiness

Cons:
- Requires review process
- Updates take longer
- May require certain popularity/download thresholds

**Conclusion**: Use custom tap initially, consider migration to homebrew-core if popularity grows

### 2. Commit Formula Directly from GitHub Actions

Similar to current cargo-dist approach but with manual Formula management.

Cons:
- Requires manual maintenance
- Manual checksum updates on version changes

**Conclusion**: Current cargo-dist automation approach is superior
